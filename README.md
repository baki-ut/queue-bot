# Бот очереди на сдачу практических работ

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `pyproject.toml` | описание проекта и список библиотек (аналог `build.gradle.kts`) |
| `.python-version` | какую версию Python использовать — uv скачает её сам |
| `uv.lock` | точные версии библиотек; создаётся сам при первом `uv sync`, его надо коммитить |
| `.venv/` | папка с установленными библиотеками; создаётся сама, в git не кладётся |
| `bot.py` | точка входа: запуск бота |
| `common.py` | настройки из `.env` и общая логика |
| `buttons.py` | меню на кнопках |
| `keyboards.py` | сами кнопки |
| `commands.py` | текстовые команды |
| `db.py` | очередь и база SQLite |
| `subjects.py` | список предметов |
| `schedule.py` | расписание и правила, когда можно записываться |
| `access.py` | доступ только для своей группы |
| `cleanup.py` | автоудаление сообщений |
| `.env.example` | шаблон настроек; копия `.env` с вашим токеном в git не кладётся |

## Запуск

1. Установите uv (один раз на компьютер):
   - Windows (PowerShell): `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
   - Linux/macOS: `curl -LsSf https://astral.sh/uv/install.sh | sh`
2. В папке проекта:
   ```bash
   uv sync
   ```
   uv скачает нужный Python, создаст `.venv` и поставит библиотеки.
3. Создайте бота у @BotFather, скопируйте `.env.example` в `.env` и впишите токен.
4. Запустите:
   ```bash
   uv run bot.py
   ```
5. Напишите боту `/id`, впишите свой ID в `ADMIN_IDS` в `.env`, перезапустите бота.
6. Добавьте бота в группу, напишите там `/chatid` и впишите полученное число (обычно начинается с `-100`) в `ALLOWED_CHAT_ID` в `.env`. Перезапустите бота.
7. В @BotFather: `/setjoingroups` → выберите бота → **Disable**, чтобы его нельзя было добавить в другие группы.

## Доступ

Если `ALLOWED_CHAT_ID` задан, бот отвечает только в этой группе и в личке её участникам. В чужих группах он молчит, а их ID пишет в лог (`journalctl -u queue-bot | grep ALLOWED_CHAT_ID`). Команды `/id` и `/chatid` работают везде — они нужны для настройки.

Добавить библиотеку: `uv add имя`. Удалить: `uv remove имя`.

## Предметы

мбп, оирткпс, тестирование, рбд, котлин. Список лежит в `subjects.py`: чтобы добавить предмет, допишите строку и перезапустите бота. Предметы с темами перечислены там же в `SUBJECTS_WITH_TOPICS`.

## Как пользоваться

Напишите `/menu` — появится меню с кнопками:

- **📝 Записаться** → выбрать предмет → бот спросит номер ПР (для МБП сначала тему). Номер отправляется отдельным сообщением в ответ на вопрос бота. Передумали — напишите «отмена».
- **🚪 Выйти из очереди** → выбрать предмет.
- **📋 Очереди** → предмет или «Все очереди», кнопка «Обновить» перерисовывает список.
- **👤 Мои записи** → всплывающее окно, видно только вам.
- **🕒 Сегодня** → пары на сегодня и на что сейчас открыта запись.
- **🎓 Для старосты** → выбрать предмет → панель с кнопками «Вызвать следующего», «Сдал», «Не сдал». Вызванного бот отмечает в группе отдельным сообщением.

## Команды

Всё то же можно делать текстом:


| Команда | Кто | Что делает |
|---|---|---|
| `/join предмет N` | все | встать в очередь, например `/join рбд 2` |
| `/join мбп тема N` | все | для МБП ещё и тема: `/join мбп 1 2` — тема 1, ПР 2 |
| `/leave предмет` | все | выйти из очереди по предмету |
| `/queue` | все | все очереди; `/queue рбд` — одна |
| `/me` | все | мои записи и места в очередях |
| `/today` | все | пары сегодня и на что открыта запись |
| `/next предмет` | староста | вызвать следующего |
| `/done предмет` | староста | текущий сдал → вызвать следующего |
| `/skip предмет` | староста | текущий не сдал → убрать, вызвать следующего |

## Когда можно записаться

Время московское. Расписание лежит в `schedule.py`: `EVERY_WEEK` — пары, одинаковые каждую неделю, `ODD_WEEK` и `EVEN_WEEK` — отличающиеся по нечётным и чётным неделям. 1-я неделя нечётная, начинается 31 августа.

1. В день с парами — с начала первой пары −1 час до конца последней +1 час.
2. В день без пар — с 9:00 до 19:00.
3. Очередь по предмету — на его ближайшую практику. Если практика идёт сейчас, запись идёт на неё. Когда практика закончилась (у сдвоенной — после второй пары), бот сам очищает очередь, и начинается запись на следующую. Лекции не считаются.

В `/queue` у каждой очереди видно, на какую она пару: «идёт сейчас, до 15:50» или «пн 05.10, 12:40».

Выйти из очереди, посмотреть её и работать старосте можно в любое время. Для проверки бота вне учебного времени поставьте в `.env` `SCHEDULE_ENABLED=0`.

## Автоудаление сообщений

Чтобы бот не засорял чат:

- промежуточные сообщения записи (выбор предмета, вопросы бота, ваши ответы с номерами) удаляются сразу, как только запись завершена или отменена;
- итоговый ответ бота и ваша команда — через `CLEANUP_DELAY` секунд (по умолчанию 60);
- меню и списки, которыми не воспользовались, — через `MENU_TTL` секунд (по умолчанию 300);
- команда `/menu` удаляется сразу.

Не удаляются: панель старосты (она нужна всю пару), сообщения «ваша очередь» с упоминанием и справка `/start` в личке.

**Чтобы бот удалял и сообщения участников**, в группе сделайте его администратором с одним правом — «Удаление сообщений». Без этого он удаляет только свои сообщения. Выключить автоудаление: `AUTODELETE=0` в `.env`.

## Правило приоритета

У каждого предмета своя очередь, можно стоять в нескольких сразу. Внутри предмета:

1. Тот, кого уже вызвали, остаётся первым до `/done` или `/skip`.
2. Дальше ожидающие по номеру работы: ПР 1 раньше ПР 2. У МБП сначала сравнивается тема, потом номер ПР: тема 1, ПР 3 идёт раньше темы 2, ПР 1.
3. Внутри одного номера — кто раньше записался.

Уведомление «ваша очередь» приходит в личку, только если человек хотя бы раз написал боту `/start` в личных сообщениях.
